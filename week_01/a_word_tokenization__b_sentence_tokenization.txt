PROGRAM: 1.a) word_tokenization
===============================

CODE:
'''1.a) word_tokenization'''

import nltk
nltk.download('punkt')
nltk.download('punkt_tab')

from nltk.tokenize import word_tokenize

text = "Hello everyone. Welcome to NLP class."
print(word_tokenize(text))

===================================

CODE:
'''1.b) sentence_tokenization'''

import nltk
nltk.download('punkt')
nltk.download('punkt_tab')

from nltk.tokenize import sent_tokenize

text = "Hello everyone. Welcome to class. Learn NLP."
