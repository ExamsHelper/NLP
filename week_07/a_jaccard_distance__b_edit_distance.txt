PROGRAM: 7.a) jaccard_distance
==============================

CODE:
'''7.a) jaccard_distance'''

from nltk.metrics.distance import jaccard_distance
from nltk.util import ngrams

word1 = "good"
word2 = "google"

a = set(ngrams(word1, 2))
b = set(ngrams(word2, 2))

print(jaccard_distance(a, b))

OUTPUT:
0.6666666666666666
